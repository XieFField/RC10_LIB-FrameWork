# artifacts 说明

该目录用于存放 AI 协作过程中的参考产物、中间附件与可追溯摘要，不用于存放业务源码副本。

## 当前目录职责

- `ai2_artifacts/`
  - 当前 AI 回归与分析过程的产物归档根目录
  - 典型用途包括：
    - `swerve_port` 聚合回归的 JSON / 摘要输出
    - `lock_now_rot_z` 缺陷复现与修复验证产物
- `comment_restore_refs/`
  - 注释恢复、注释对照、恢复参考资料目录
  - 更偏参考物与对照资料，不应替代主文档

## 哪些内容适合放这里

- 由测试脚本或分析过程生成的 JSON、摘要、截图、对照材料
- 需要留档以便回溯的过程附件
- 不适合放进主文档、但仍需要保留出处的信息

## 哪些内容不建议放这里

- 业务源码副本
- 可以轻易重建、却没有写明来源的临时产物
- 没有上下文说明、后续无法理解用途的零散文件

## 维护约定

- 能由脚本重建的产物，尽量在对应文档里注明来源与重建方式。
- 若某类产物已不再需要保留，应先确认是否已经在 handoff 或测试文档中留下足够证据。
- 目录职责以 [../catalog/artifacts.yaml](../catalog/artifacts.yaml) 为准，本页主要负责给人快速导航。
