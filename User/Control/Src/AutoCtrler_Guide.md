# AutoCtrler 模块 - 详细说明文档

## 1. 概述

`AutoCtrler` 是一个为特定场景设计的机器人高级路径决策模块。其核心功能是根据机器人当前的位置以及一或两个“物料点”（MF, Material Feeder）任务，计算出一条最优的宏观路径节点序列。

这条路径通常包含以下关键节点：
- **入口点 (Entrance)**: 机器人从场外进入工作区域的最佳切入点。
- **任务过渡点 (B1, B2)**: 执行物料任务前后的路径点。
- **物料交互点 (BMF1, BMF2)**: 实际执行物料任务（如抓取/放置）的邻近点。
- **出口点 (Exit)**: 任务完成后离开工作区的固定点。

模块通过计算不同路径组合的总成本（结合了场外欧氏距离和场内网格步数），来寻找成本最低的节点序列。

## 2. 核心概念

### 2.1. 地图模型
- **网格地图**: 整个工作区域被抽象为一个 6行 × 5列 的网格地图，共30个单元格，编号从1到30。
- **坐标系统**:
    - **地图编号 (MapNum)**: 1-30的整数，唯一标识每个单元格。
    - **行列坐标 (c, r)**: `c` 为列（1-5），`r` 为行（1-6）。
    - **世界坐标 (Point2D)**: 每个单元格中心点在真实世界中的物理坐标（米）。`MapNum_RealPos` 数组存储了每个地图编号对应的世界坐标。
- **障碍区域**: `IsWalkable(map)` 函数定义了地图的可通行区域。当前实现中，地图中央的一个矩形区域被硬编码为障碍物。

### 2.2. 物料点 (MFNum)
- **MFNum**: "Material Feeder Number" 的缩写，代表需要执行任务的特殊点位。它有自己独立的编号体系（例如1-12）。
- **映射关系**: `MFNum_TransforMapNum` 和 `MapNum_TransforMFNum` 函数用于在 `MFNum` 和 `MapNum` 之间进行转换。

## 3. 主要功能函数

### 3.1. `PathNode_S PathNodeResult_calc(Point2D robotPos, int8_t MF1, int8_t MF2)`
这是模块最核心的决策函数。

- **功能**: 计算从机器人当前位置出发，依次完成 `MF1` 和 `MF2` 两个任务，最后到达出口的最优路径节点序列。
- **参数**:
    - `robotPos` (Point2D): 机器人当前的世界坐标。
    - `MF1` (int8_t): 第一个物料任务点的 `MFNum`。
    - `MF2` (int8_t): 第二个物料任务点的 `MFNum`。如果只有一个任务，可以传入0。
- **返回值**: `PathNode_S` 结构体，包含计算出的最优节点序列：
    - `.entranceMap`: 最佳入口点的 `MapNum`。
    - `.bestB1`: 第一个任务的过渡点。
    - `.bestBMF1`: 第一个任务的交互点。
    - `.bestB2`: 第二个任务的过渡点（如果存在）。
    - `.bestBMF2`: 第二个任务的交互点（如果存在）。
    - `.exitMap`: 固定的出口点 `MapNum` (值为30)。

### 3.2. `int BFS_Steps(int8_t startMap, int8_t goalMap)`
- **功能**: 使用广度优先搜索（BFS）算法，计算在网格地图上从 `startMap` 到 `goalMap` 的最短路径步数。
- **返回值**:
    - `0`: 起点和终点相同。
    - `> 0`: 最短步数。
    - `BFS_INF` (30000): 两点之间不可达。

### 3.3. 辅助函数
- `MFNum_ToRoadResult(MFNum)`: 查找一个 `MFNum` 对应的“道路”节点（任务过渡点）。
- `MFNum_ToCatchRoadResult(MFNum)`: 查找一个 `MFNum` 对应的“抓取”节点（任务交互点）。
- `Map_ToCR`, `CR_ToMap`: 在地图编号和行列坐标之间转换。
- `IsWalkable`: 判断一个地图单元格是否可通行。

## 4. 工作流程与决策逻辑

`PathNodeResult_calc` 的决策逻辑可以概括为：

1.  **确定候选节点**:
    - 根据 `MF1` 和 `MF2`，使用 `MFNum_ToRoadResult` 和 `MFNum_ToCatchRoadResult` 找出所有可能的 `B1`, `BMF1`, `B2`, `BMF2` 候选点。
    - 根据机器人位置，确定所有可能的入口点 `E`。
2.  **遍历所有路径组合**:
    - 通过多层嵌套循环，遍历所有可能的路径组合，例如 `E -> B1 -> BMF1 -> B2 -> BMF2 -> Exit`。
3.  **计算每条路径的成本**:
    - **场外成本**: 机器人当前位置到入口点 `E` 的直线欧氏距离。
    - **场内成本**: 路径上各节点之间通过 `BFS_Steps` 计算出的网格步数之和，再乘以每个格子的标准长度 `CELL_M`。
    - **总成本 = 场外成本 + 场内成本**。
4.  **选择最优路径**:
    - 记录并更新成本最低的路径组合，并将其作为最终结果返回。
5.  **备用逻辑**: 如果找不到完整的路径，函数会执行一个简化逻辑，确保至少能规划出到第一个任务点的路径。

## 5. 如何使用

在你的控制逻辑中，当需要执行自动任务时：

1.  获取机器人当前的世界坐标 `robotPos`。
2.  确定需要执行的一个或两个物料任务的 `MFNum`。
3.  调用 `PathNodeResult_calc` 函数。
4.  获取返回的 `PathNode_S` 结构体，这就是机器人需要依次经过的宏观路径点。
5.  接下来，你可以使用更底层的路径规划器（如A*、贝塞尔曲线等）来生成并执行从一个宏观节点到下一个节点的具体轨迹。
