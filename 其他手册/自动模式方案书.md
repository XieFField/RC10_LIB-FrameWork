
## 梅花林自动拾取KFS

### 路径规划部分

可取桩位为
左一列：1, 4, 7, 10     
中一列：2, 11
右一列：3, 6, 9, 12

*以下提到的速度均为世界坐标系下的速度；采用右手系*

至于梅花林地图的简化处理。

将原本$3*4$的梅花林加上外围一圈的通道切割成$5*6$的一个地图(梅花林是在中间$3*4$的矩形方格，外围一圈是通道)
方格的数字号按从左到右依序排列上去。
每个方格都为$1200mm * 1200mm$

则原本梅花桩数字号对应新的排列方式的关系是(伪代码)
```cpp
static inline int8_t MFNum_TransforMapNum(int8_t MFNum)
{

    if(MFNum < 1 || MFNum > 12)
        return -1;

    return MFNum + 6 + 2 * ((MFNum - 1) / 3.0);
}

static inline int8_t MapNum_TransformMFNum(int8_t mapNum)
{

    int8_t MFNum_ = mapNum - 6 - 2 * ((mapNum - 7) / 3);

    if(MFNum_ < 1 || MFNum_ > 12)
        return -1;

    return MFNum_;
}
```

#### 梅花林自动寻路中的必经点计算

那么对应的，要拾取每个梅花桩上的KFS，底盘沿通道行进，在到达目标桩跟前的通道方块A之前；要先在A之前的通道方块B开启拾取预测计算以及最少在B此处将非沿着通道方向的速度降低为0(即此处底盘走的通道方向为Y轴方向的话，那么X轴向速度就要为0);
如果不考虑最优路径的话，对应MFNum编号的梅花桩的拾取通道可以有多解(最多3解)，满足关系
(伪代码)
```cpp
typedef struct{
	int8_t result1 = 0;
	int8_t result2 = 0;
	int8_t result3 = 0;
}RoadResult_S;
static inline RoadResult_S MFNum_ToRoadResult(int8_t MFNum)
{
	RoadResult_S result = {0, 0, 0};
	if(MFNum < 1 || MFNum > 12)
        return result;
	
	int8_t mapNum_ = MFNum_Transform(MFNum);
	
	int8_t candidate[4];
	candidate[0] = mapNum_ - 6;
	candidate[1] = mapNum_ - 4;
	candidate[2] = mapNum_ + 4;
	candidate[3] = mapNum_ + 6;
	
	for(int i = 0; i < 4; i++)
	{
		int8_t mf = MapNum_TransformMFNum(candidate[i]);
		//过滤
        if(mf < 1 || mf > 12)
            candidate[i] = 0;
	}
	

	int8_t validResults[3] = {0}; 
    int validCount = 0;
    //过滤0
    for(int i = 0; i < 4 && validCount < 3; i++)
    {
        if(candidate[i] != 0)
        {
            validResults[validCount++] = candidate[i];
        }
    }

	//排列
	for(int i = 0; i < validCount - 1; i++)
    {
        for(int j = 0; j < validCount - 1 - i; j++)
        {
            if(validResults[j] > validResults[j+1])
            {
                int8_t temp = validResults[j];
                validResults[j] = validResults[j+1];
                validResults[j+1] = temp;
            }
        }
    }

	result.result1 = validResults[0];
    result.result2 = validResults[1];
    result.result3 = validResults[2];
    
    return result;
}
```

```cpp
// 2D点结构体

typedef struct  {

    float x, y;

} Point2D;

static inline Point2D MapNum_ToMatrixPos(int8_t MapNum)
{
	Point2D result_ = {0, 0}; 
	
	result.y = (MapNum - 1) / 5 + 1;
	result.x = (MapNum - 1) % 5 + 1;
	return result_;
}
```

并通过当前底盘的真实位置，去计算经过的前一桩的优解(必经过的点)，然后先经过优解点1，再经过优解点2，最后经过而所有路径的终点都是19号格子(上斜坡到竞技场)。

- 两段验证
	1. 最优入口 enter
		计算：当前底盘位置到入口，再到最优点1的连线最短
		1. 欧氏距离段:$d_{out}(e) = ||p − c(e)||^2$
		2. BFS段：$s(e) = min_{b\in B_{1}} \,\,BFS_{steps(e\to b)}$ $s(e) * CELL转换成米$
		3. 总成本：$J(e)=d_{out}+s(e)*CELL$ 
		4. 最优入口：$e^*= argmin_e J(e)$
	2. 最优点1：$b_{1}^* = argmin_{b∈B1} BFS_{steps(e*→b)}$
	3. 最优点2：以$b1*$为起点：$b_{2}^* = argmin_{b∈B2}*BFS_{steps(b1*→b)}$
